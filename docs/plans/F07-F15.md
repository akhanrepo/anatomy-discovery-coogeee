# Plan F07 + F15 — Share cards, /today, RSS, email

**Approach.**
- **OG images:** `src/pages/og/[id].png.ts` and `og/default.png` (satori → resvg). Plate-style 1200×630 with the plate rendered as an embedded SVG image, Tab. number, title, date and the "On this day / This week" kicker. Fonts are EB Garamond and IM Fell from `@fontsource` WOFF files.
- **`/today/`:** server-renders all 52 weekly cards hidden; a tiny inline script picks today's card (`cardFor`) in the browser. A static fallback (this build's week) is visible without JS, so the page is never empty.
- **`/editor/cards/`** (unlisted, `noindex`): the year's schedule with captions and download links to the OG PNGs.
- **`/feed.xml`:** RSS 2.0 with one item per calendar slot (52) + on-this-day items, valid per the W3C rules (channel title/link/description; item guid/pubDate RFC-822).
- **Email:** `src/components/Subscribe.astro` (Buttondown embed form when configured; RSS link always) in the footer, after the 3rd story and on /today. `subscribe` events fire on submit or RSS click. `scripts/build-artefacts.ts` writes `artefacts/email/week-NN.html`, a table-based, inline-styled email for each week (the issue is drafted, Ali sends it).
