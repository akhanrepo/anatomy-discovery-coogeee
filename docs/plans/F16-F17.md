# Plan F16 + F17 — Visual system and brand

> Process note: written during implementation of the core batch (the agreed process is plan-first; later features follow it).

**Approach.** Tokens live in `src/styles/global.css` and `src/styles/tokens.ts` (used for standalone SVG/PNG). The ink states are pure CSS on `data-state` (`ghost`/`ink`/`hatch`/`wash` layers per structure) with transition timings in tokens. Paper per era comes from `body[data-paper]`. Dark mode is "candlelit". The icon (`scripts/gen-icons.ts`) is a half-inked heart, with a two-tone 16px variant and an adaptive favicon. The name and tagline live only in `src/config/site.ts`.

**Deviation (honest):** the figure is our own schematic engraving in anatomical position, not yet the commissioned *Epitome*-based engraving. Structure IDs are stable, so the commissioned art swaps in one-for-one.
