# Plan: F18 open-source release

Brief: [F18](../features/F18-open-source-release.md). Reference: the same work on `akhanrepo/flight-dictation` (its feature 11).

## Approach
1. **Briefs first.** Update F12 (packs are free; AC3 becomes "free download"), F14 (the edition is free; no licence-key web unlock), F08 (`checkout_start` → `download`) and the PRD (status note, personas, business model, commerce stack). Add F18 to the PLAN status table.
2. **Remove commerce.** Delete `BuyButton.astro`, `.btn.buy`, and `site.commerce`. `/teachers` and `/edition` link to free downloads, and the pack cover licence line becomes CC BY-SA.
3. **One download list.** `src/lib/downloads.ts` holds the stable file names (`tabula-pack-<id>-<a4|letter>.pdf`, `tabula-edition.epub`, `tabula-edition.pdf`) and `downloadUrl()` (`<repo>/releases/latest/download/<file>`). `scripts/build-artefacts.ts` writes those names, and the release workflow uploads `artefacts/packs/*.pdf` and `artefacts/edition/tabula-edition.{epub,pdf}`. Download clicks fire a `download` event (F08).
4. **Licences.** `LICENSE` (MIT, © 2026 Ali Khan), `LICENSE-CONTENT` (verbatim CC BY-SA 4.0 legal code), `"license": "MIT"` plus `repository` and `homepage` in `package.json`, a footer licence line, an "Open source" section on `/about`, and a licence map in the README.
5. **Identity and contact.** Set `site.repo` to `akhanrepo/tabula`. `contactEmail` comes from `PUBLIC_CONTACT_EMAIL` (empty means hidden), and `donateUrl` from `PUBLIC_DONATE_URL`. Corrections use `issues/new?template=correction.yml&story=…&claim=…`.
6. **Repository files.** README (rewritten in Flight's style), CONTRIBUTING (including how to add or correct a discovery under F05), CODE_OF_CONDUCT (Contributor Covenant 2.1), SECURITY (private advisories, with a scope for a static site), CHANGELOG (1.0.0), THIRD_PARTY_NOTICES, `docs/architecture.md`, `.editorconfig`, `.nvmrc`.
7. **.github.** Issue forms (bug, correction, feature) plus config, PR template, CODEOWNERS, Dependabot (npm grouped, plus actions), workflows: `ci.yml` (lint, unit, build, e2e; perf runs as a separate non-blocking job because shared runners are too noisy for millisecond budgets), `codeql.yml` (public only) and `release.yml` (tag → verify the version → build → artefacts → release with notes from CHANGELOG).
8. **Portable Chromium.** `scripts/chromium.mjs` is shared by `playwright.config.ts` and `build-artefacts.ts`.
9. **Dependencies.** `npm audit fix` (non-breaking: undici, zod). The remaining moderate advisory (fflate via satori) needs a satori downgrade, so it is left and noted.

## Risks
- **Release links 404 until the first tag.** Mitigation: the manual steps put "push v1.0.0" right after the merge, and the free sample stays on the site.
- **Perf budgets on CI runners.** They're reported but don't block, and they stay blocking locally (`npm run test:all`).
- **The rename.** GitHub redirects old URLs. Netlify must be re-linked (manual step).
