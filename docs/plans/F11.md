# Plan F11 — Timeline, people and threads (tours)

**Approach.** Static pages are generated from existing data, with no new data beyond `Thread` records:
- `/timeline/`: discoveries and misbeliefs in date order, on an engraved rule with the panorama strip.
- `/people/` and `/people/[id]/`: name in original script, dates, place, tradition; their discoveries and the misbeliefs they held.
- `/threads/` and `/threads/[id]/`: the intro and the ordered stories, plus **Play this tour**, which links to `/?tour=<id>`.

The controller reads `?tour=` and drives the body: it opens each story in turn, the year moves with it, and a tour bar offers Prev / Pause-Resume / Next / Exit, all as buttons, so it's fully keyboard operable. It auto-advances every 12s, and Space toggles pause.

**Files:** `src/pages/timeline.astro`, `src/pages/people/index.astro`, `src/pages/people/[id].astro`, `src/pages/threads/index.astro`, `src/pages/threads/[id].astro`, `src/components/TourBar.astro`, `src/client/app.ts` (tour mode), `tests/e2e/functional/browse.spec.ts`.
