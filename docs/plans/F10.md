# Plan F10 — Traditions lens

**Approach.** Built in the core batch: `LensView.astro` renders one section per tradition. It shows a Tabula schematic drawn *after* the source plate (`src/art/lenses.ts`), numbered hotspots, and concept articles with "relation to modern anatomy" and sources. The original plate is displayed **only** when its asset has `licenceVerified: true` and a local `file`; otherwise the schematic is shown with a link to the record. Every lens view and concept carries the disclaimer.

**Remaining work:** the lens functional tests and a `?lens=` deep link (already in the URL state).

| AC | Test |
|---|---|
| F10-AC1 | `tests/unit/lens.test.ts`: ≥ 6 concepts per lens; each claim has a scholarly source with a locator; gates pass |
| F10-AC2 | `lens.test.ts`: every concept has `relatesTo` (with `none` allowed) |
| F10-AC3 | `lens.test.ts`: no lens shows an original plate whose licence is unverified or disallowed + `lens.spec.ts`: the schematic, not the original, is rendered while unverified |
| F10-AC4 | `tests/e2e/functional/lens.spec.ts`: the disclaimer is visible on each lens and concept |
