## Brief template

Every brief uses the same sections:

- **Summary**: one paragraph
- **User problem / job**: what the user is trying to do
- **User stories**
- **Scope**: in / out
- **Behaviour & UX notes**
- **Acceptance criteria**: testable
- **Data & dependencies**
- **Risks & accuracy notes**
- **Open questions**
